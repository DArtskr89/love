Как открыть на компьютере:
1. Распакуйте ZIP.
2. Дважды нажмите index.html.

Как выложить через GitHub Pages:
1. Создайте новый public-репозиторий на GitHub.
2. Загрузите ВСЕ файлы и папку assets из этой папки в корень репозитория.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Source: Deploy from a branch.
5. Branch: main, папка /(root), затем Save.
6. Через несколько минут GitHub покажет ссылку на сайт.

Важно про музыку:
Браузеры на телефонах запрещают автозапуск звука без действия пользователя.
Поэтому фоновая песня стартует в момент первого нажатия на конверт — это сделано специально.

Файлы:
- assets/audio/background.mp3 — фоновая музыка
- assets/audio/harvey.m4a — песня Harvey в плеере
